## Root cause and fix

`RosGzBridge` owns each bridge through
`std::vector<std::shared_ptr<BridgeHandle>> handles_`. Before this candidate,
every `BridgeHandle` also retained the owning `RosGzBridge` node through an
`rclcpp::Node::SharedPtr`. That creates this strong-reference cycle:

```text
RosGzBridge node -> handles_ -> BridgeHandle -> ros_node_ -> RosGzBridge node
```

After `rclcpp::spin()` returned, the local node pointer could not destroy the
node, bridge handles or Fast DDS endpoints. The failing backtraces then reached
process finalization with middleware threads and shared libraries still alive.

The patch changes only the handle-to-node back-reference to
`rclcpp::Node::WeakPtr` and locks it at the few sites that need node access.
This breaks the cycle while preserving the node-to-handle ownership needed at
runtime.

Retained patch:
[`patches/ros_gz_bridge_handle_cycle_fix.diff`](../../../patches/ros_gz_bridge_handle_cycle_fix.diff)

ros_gz_bridge from its own install prefix. Its runtime matrix passed eight topic
conversions, one ControlWorld service conversion, and 10/10 active

coverage under emulation, not native x86_64 hardware coverage.

## Upstream package test suite

The candidate was reconfigured with `BUILD_TESTING=ON`. A constrained
two-worker build completed successfully. CTest then passed **17/18** targets;
the compiled conversion tests, launch tests, `cppcheck`, `cpplint`, `flake8`,
`lint_cmake`, `pep257`, and `uncrustify` all passed. `colcon test-result`
reported 386 test cases, with 72 skipped and one missing-result failure.

The only failed target was `xmllint`. It timed out after 60 seconds while
`ament_xmllint` was downloading the remote ROS package schema and never
generated its xUnit file. A direct transfer independently stalled after 1,036
of 8,027 bytes. The exact, unmodified candidate `package.xml` then passed
`xmllint --schema` against the canonical schema fetched from the ROS
`ros-infrastructure/rep` repository. `ament_xmllint` also passed on a temporary
copy whose only change was replacing the remote schema URL with that local
schema path. No production XML file was changed.

Evidence:
[`upstream_test_suite/`](upstream_test_suite/).

The first `BUILD_TESTING` attempt used unconstrained parallel compilation and
exceeded the Docker 11.67 GiB memory limit while compiling multiple generated
test translation units. It is retained as an invalid resource/harness attempt;
the valid rerun limited compilation to two workers.
