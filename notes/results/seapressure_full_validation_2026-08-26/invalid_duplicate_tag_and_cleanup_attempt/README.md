# Excluded first full-matrix attempt

This attempt is preserved only to show why it was rejected. It cannot support any
SeaPressure verdict.

Two independent fixture defects were found:

1. process-name cleanup did not stop the previous Gazebo world, so later models
   accumulated in an old server;
2. the generated SDF duplicated tested elements instead of replacing the base value.

The two retained SDF files show the duplicate `kPa_per_meter` and
`estimate_depth_on` elements. `runner.log` shows plausible per-condition exit
reports despite the broken isolation. Result JSON and launch logs from this attempt
were removed from the canonical evidence set to prevent accidental use.

The valid results are the sibling `05_parameter_matrix/` and
`06_docker_validation/` directories, generated by the corrected one-server,
unique-namespace, one-tag-per-setting runner.
